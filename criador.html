Carga por planilha (com fotos)
  1. Baixe a planilha modelo e preencha uma linha por produto. Se o cliente já tem produtos, eles vêm na planilha para você editar.

    Na coluna foto, coloque o caminho da foto (ex.: C:\Fotos\Dom Manolo\corte-degrade.jpg), só o nome do arquivo (corte-degrade.jpg) ou um link https.

Ou cole as linhas aqui

O navegador não abre fotos do computador só pelo endereço, por segurança. Por isso você escolhe a pasta, e o criador encontra cada foto pelo nome do arquivo. Fotos HEIC do iPhone precisam ser convertidas para JPG antes.

Sem produtos, o site mostra só os botões grandes, como uma bio comum.

Painel do dono (mudar preços pelo celular)

O dono abre um link, digita o código de acesso e muda preços e "esgotado" sozinho. O site atualiza em cerca de 1 minuto.

Configurar GitHub e Vercel (uma vez só)
  1. Repositório tiagoingles/biosite e projeto biosite na Vercel já estão criados e ligados.
  2. Crie um token em GitHub → Settings → Developer settings → Fine-grained tokens: acesso só ao repositório biosite, permissão Contents: Read and write.
  3. Cole o token acima e clique em Salvar e testar.
  4. Quando ligar um domínio próprio, troque o "Endereço do site".
